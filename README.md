# 💼 Job Hunt

A full-stack MERN Job Portal that connects job seekers with recruiters. Users can browse and apply for jobs, while recruiters can manage companies, post job openings, and track applicants through an intuitive dashboard.

🌐 **Live Demo:** https://job-hunt-sigma-nine.vercel.app/

---

## 🚀 Features

### 👨‍💼 Job Seeker
- Create and manage user accounts
- Browse all available jobs
- Search jobs by keyword
- View detailed job descriptions
- Apply for jobs with a single click
- Track applied jobs
- Update profile information

### 🏢 Recruiter/Admin
- Recruiter authentication
- Create and manage companies
- Post new job openings
- Edit and update job details
- View all posted jobs
- Track applicants for each job
- Manage company information

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/Job-Hunt.git
cd Job-Hunt
```

### Backend Setup

```bash
cd server
npm install
npm run dev
```

### Frontend Setup

```bash
cd client
npm install
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file inside the server folder.

```env
PORT=8000

MONGO_URI=your_mongodb_connection

SECRET_KEY=your_secret_key

CLOUD_NAME=your_cloudinary_name

API_KEY=your_cloudinary_api_key

API_SECRET=your_cloudinary_api_secret

FRONTEND_URL=http://localhost:5173
```
